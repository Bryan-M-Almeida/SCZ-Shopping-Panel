# SCZ Shopping

A console-based inventory and sales management system developed in C.

[English](README.md) | [Español](README.es.md) | [Português](README.pt-BR.md)

## About the Project

SCZ Shopping is a console application designed to simulate the basic operations of a small store.

The project was developed in C with a focus on practicing fundamental programming concepts such as:

- Functions
- Structures (`struct`)
- Arrays
- File handling
- Input validation
- Searching algorithms
- Sorting algorithms
- Modular programming
- Basic inventory management

## Features

- Register products
- List registered products
- Search products by code
- Edit product information
- Delete products
- Register sales
- Automatically update inventory after sales
- Sort products by price
- Save product data to a file
- Load saved data when starting the application
- Validate product codes, prices, quantities, and stock availability

## Main Files

| File        | Description                                 |
| ----------- | ------------------------------------------- |
| `main.c`    | Main program and interactive menu           |
| `product.c` | Product and inventory management logic      |
| `product.h` | Product structure and function declarations |
| `file.c`    | Data persistence and file operations        |
| `file.h`    | File-related declarations                   |
| `data/`     | Directory used to store local product data  |

## Data Storage

Product information is stored locally in:

```
data/products.txt
```

The file is generated by the application when the user saves the data.
The actual data file is intentionally excluded from version control because it contains local application data.

## Requirements

- C compiler
- GCC recommended
- Git
- Terminal

## Compilation

Using GCC:

```
gcc main.c product.c file.c -o scz-shopping
```

On Windows:

```
gcc main.c product.c file.c -o scz-shopping.exe
```

## Running

# Linux/macOS:

```
./scz-shopping
```

# Windows

```
scz-shopping.exe
```
